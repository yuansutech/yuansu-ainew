FAQ

常见问题

网页版和 exe 有什么区别？
功能一样。网页版打开即用，不用装东西；exe 是单文件桌面程序，离线也能跑，适合常用的人。两者底层都是调三家官方 API。
需要 API Key 吗？
需要。你得先到通义千问、DeepSeek、智谱三家平台各自申请一个 API Key。三家都有免费额度，日常玩够用。
支持哪些模型？
默认三家：Qwen（qwen-turbo）、DeepSeek（deepseek-flash）、智谱（glm-4-flash）。想用重模型，改代码顶部三行就行。
收费吗？
程序本身完全免费、开源。你只需要自己承担三家平台的 API 调用费用。用轻量模型的话，聊天一轮大约几厘钱，一晚上几块钱封顶。
能自己改提示词吗？
能。三种模式的 system prompt 都写在对应文件里，直接改文字就行。
可以贡献代码吗？
欢迎。项目仓库在 GitHub 上，提交 Issue 或 PR 都行。
